# Pedal2Patch — Politique de confidentialité (version actuelle)

Dernière mise à jour : 2026-10-04

Pedal2Patch est actuellement une application côté client. Dans cette version du prototype, les informations saisies dans l'interface et les photos sélectionnées pour préparer un pedalboard sont traitées localement par l'application ; aucun serveur Pedal2Patch n'est requis pour le fonctionnement de base.

## Données
- Les réglages de patch peuvent être exportés volontairement en JSON.
- Une photo de pedalboard sélectionnée par l'utilisateur reste une ressource locale de la session dans la version actuelle.
- Aucun compte utilisateur ni synchronisation cloud Pedal2Patch n'est implémenté dans cette version.

## Intégrations futures
Toute intégration de reconnaissance d'image, analytics, publicité, achats intégrés, synchronisation cloud ou envoi réseau vers une console devra être documentée avant activation et faire l'objet des informations et consentements requis.

Cette page décrit uniquement la version actuelle du logiciel et ne constitue pas encore la fiche juridique finale de publication Google Play.
